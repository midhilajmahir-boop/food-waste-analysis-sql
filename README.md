# Food Waste Management Analysis using SQL

## Project Overview
This project analyzes food waste data using PostgreSQL to identify waste patterns, understand business performance, and generate actionable insights to support better inventory and food waste management decisions.

## Project Objectives
- Analyze food waste across different business types.
- Identify food categories with the highest waste.
- Evaluate purchasing, sales, and remaining stock.
- Understand the impact of weather and promotions on food waste.
- Analyze donation patterns.
- Generate business insights using SQL.

## Tools & Technologies
